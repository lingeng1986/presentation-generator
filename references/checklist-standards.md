# PDF Presentation Checklist Standards

通用幻灯片规范、最佳实践和检查标准。

## 1. 视觉规范 (Visual Standards)

### 1.1 颜色
- [ ] **背景色显示正确**：不是白色/灰色，与设计一致
- [ ] **渐变色完整**：没有断层或色带
- [ ] **文字对比度**：白色文字在彩色背景上清晰可读
- [ ] **主题色一致性**：每页颜色符合设计系统（蓝/橙/绿/黄）

### 1.2 排版
- [ ] **文字未截断**：所有文字完整显示，没有被切掉
- [ ] **对齐正确**：左右栏对齐，视觉平衡
- [ ] **间距一致**：页边距、段落间距统一
- [ ] **垂直居中**：右侧文字与左侧图片中心对齐

### 1.3 图片
- [ ] **图片加载**：没有 broken image
- [ ] **图片清晰**：分辨率足够，不模糊
- [ ] **圆角正常**：图片圆角显示正确
- [ ] **比例正确**：没有拉伸变形

## 2. 文字规范 (Typography)

### 2.1 字号
| 元素 | 最小字号 | 推荐字号 |
|------|---------|---------|
| 主标题 | 28px | 30px |
| 英文标题 | 24px | 26px |
| 中文正文 | 28px | 31px |
| 英文正文 | 22px | 24px |

- [ ] **儿童友好**：5-7岁孩子能轻松阅读
- [ ] **电视显示**：在 TV/投影上清晰可读

### 2.2 字体
- [ ] **中英文字体正确**：使用指定字体族
- [ ] **字重合适**：标题加粗，正文清晰
- [ ] **无系统回退**：没有使用备用字体

### 2.3 内容
- [ ] **无占位符**：所有 `[占位符]` 已替换
- [ ] **拼写正确**：中英文无拼写错误
- [ ] **简洁易懂**：适合目标受众认知水平
- [ ] **双语完整**：中英文都完整，没有缺失

## 3. 技术规范 (Technical)

### 3.1 PDF 质量
- [ ] **文件大小合理**：< 50MB（图片未过度压缩）
- [ ] **页数正确**：与预期页数一致
- [ ] **分页正确**：页面在正确位置断开
- [ ] **无空白页**：没有意外的空白页

### 3.2 可访问性
- [ ] **文字可选中**：PDF 中的文字可以选中复制
- [ ] **图片有 alt**：HTML 中图片有 alt 属性
- [ ] **打印测试**：打印预览正常

### 3.3 兼容性
- [ ] **A4 横向**：尺寸为 297mm × 210mm
- [ ] **打印边距**：内容在安全区域内
- [ ] **多设备**：在电脑/手机/TV 上都能正常打开

## 4. 最佳实践 (Best Practices)

### 4.1 儿童演示专用
- [ ] **句子简短**：每行不超过 10 个字
- [ ] **用词简单**：5岁孩子能听懂
- [ ] **趣味性强**：标题活泼，有吸引力
- [ ] **视觉优先**：图片为主，文字为辅

### 4.2 双语演示
- [ ] **中英对照**：中文在上，英文在下
- [ ] **字号平衡**：英文不比中文小太多
- [ ] **翻译准确**：英文表达自然，非直译
- [ ] **文化适配**：英文符合英语习惯

### 4.3 版本管理
- [ ] **命名规范**：`前缀_YYYYMMDD_HHMM_描述.html`
- [ ] **版本可追溯**：每个版本都有明确标识
- [ ] **变更记录**：知道每个版本改了什么

## 5. 任务特定检查 (Per-Task Requirements)

根据具体任务，补充以下检查项：

### 5.1 内容准确性
- [ ] **名称正确**：动物/物品名称准确
- [ ] **数量正确**：统计数字无误
- [ ] **逻辑连贯**：故事线顺畅

### 5.2 客户要求
- [ ] **特定元素**：客户要求的特殊内容已包含
- [ ] **风格匹配**：符合客户指定的风格
- [ ] **格式正确**：输出格式符合要求

### 5.3 交付标准
- [ ] **最终版本**：客户已确认
- [ ] **无已知问题**：所有反馈已处理
- [ ] **归档完整**：HTML + PDF + 素材齐全

## 6. 检查优先级

**P0 - 阻塞性问题（必须修复）**
- 图片无法显示
- 文字严重截断
- 背景色丢失
- 文件无法打开

**P1 - 重要问题（强烈建议修复）**
- 字号不符合规范
- 拼写错误
- 对齐偏差
- 内容不完整

**P2 - 优化建议（可选修复）**
- 间距微调
- 颜色微调
- 措辞优化
- 图片替换

## 7. Claude CLI 检查指令模板

```
请检查这个 PDF 演示文稿：

文件路径：[PDF_PATH]

检查标准：
1. 视觉：背景色、图片加载、文字截断、对齐
2. 文字：字号≥规范、无拼写错误、无占位符
3. 技术：文件正常、页数正确、文字可选中
4. 特定要求：[TASK_SPECIFIC_REQUIREMENTS]

请按以下格式输出：
- 总体结果：PASS / FAIL
- P0 问题：[列出阻塞性问题，无则写"无"]
- P1 问题：[列出重要问题，无则写"无"]
- P2 建议：[列出优化建议，无则写"无"]
- 置信度：High / Medium / Low
- 建议修复：[如果有问题，给出具体修复建议]
```

## 8. 检查流程

```
Step 1: 打开 PDF 文件
Step 2: 逐页检查视觉规范（颜色、图片、文字）
Step 3: 抽查文字规范（字号、拼写、内容）
Step 4: 验证技术规范（文件质量、可访问性）
Step 5: 对照任务特定要求
Step 6: 汇总问题，按 P0/P1/P2 分级
Step 7: 给出修复建议
```

## 9. 常见错误速查

| 错误 | 原因 | 修复 |
|-----|------|------|
| 背景白色 | 缺少 `print-color-adjust` | 加 CSS |
| 图片不显示 | 相对路径问题 | 用绝对路径 |
| 文字太小 | 字号设置不当 | 增大字号 |
| 页面截断 | 内容溢出 | 调整布局 |
| 文件太大 | 图片未压缩 | 压缩图片 |
| 文字不可选 | 生成问题 | 检查生成参数 |
