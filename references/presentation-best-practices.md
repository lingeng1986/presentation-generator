# 幻灯片排版规范 (Presentation Layout Standards)

核心排版与设计规范，适用于所有类型的幻灯片。

---

## 1. 字体规范 (Typography)

### 1.1 字体统一
- **标题字体**：全篇使用同一种标题字体
- **正文字体**：全篇使用同一种正文字体
- **最多 2 种字体**：一种用于标题，一种用于正文
- **中英文字体配套**：中文字体决定风格，英文与之匹配

### 1.2 字号层级
| 层级 | 用途 | 最小字号 | 推荐字号 |
|------|------|---------|---------|
| H1 | 页面主标题 | 28px | 30-36px |
| H2 | 副标题/章节标题 | 24px | 26-28px |
| Body | 正文内容 | 20px | 22-24px |
| Note | 注释/说明 | 16px | 18-20px |

**原则**：同层级文字字号必须一致

### 1.3 字重统一
- **标题**：Bold (700) 或 Heavy (900)
- **正文**：Regular (400) 或 Medium (500)
- **强调**：在同层级内用字重或颜色区分，不用字号

---

## 2. 对齐规范 (Alignment)

### 2.1 基础对齐
- **正文**：一律左对齐
- **标题**：可左对齐或居中，全篇统一
- **数字/列表**： decimal 对齐（小数点对齐）

### 2.2 模块对齐
- **网格对齐**：所有元素对齐到 8px 或 12px 网格
- **边缘对齐**：同类模块左右边缘对齐
- **中心对齐**：视觉中心线统一

### 2.3 间距一致
- **行高**：1.3-1.5 倍字号
- **段间距**：等于或大于行高
- **模块间距**：使用 8 的倍数（8, 16, 24, 32, 48）

---

## 3. 结构平衡 (Layout Balance)

### 3.1 模块结构
**左右分栏**：
```
+------------------+
|      标题         |  ← 居中或左对齐
+------------------+
|        |         |
|  左栏   |  右栏   |  ← 比例：1:1 或 1.2:0.8
|  (图片) | (文字)  |  ← 或 0.8:1.2
|        |         |
+------------------+
```

**上下结构**：
```
+------------------+
|     顶部区        |  ← 20-25%
|    (标题/导航)    |
+------------------+
|                  |
|     主视觉区      |  ← 60-70%
|   (图片/图表)     |
|                  |
+------------------+
|     底部区        |  ← 10-15%
|    (说明/来源)    |
+------------------+
```

### 3.2 视觉平衡
- **重量平衡**：左右两侧视觉重量相当
- **留白均匀**：四周留白相等或成比例
- **重心稳定**：视觉重心在页面中心偏上

### 3.3 重复与节奏
- **同类元素**：位置、大小、间距重复一致
- **页面节奏**：每页结构保持统一节奏
- **变化有度**：在统一中求变化，变化幅度一致

---

## 4. 颜色规范 (Color)

### 4.1 配色统一
- **主色**：1 个，用于标题、强调
- **辅色**：1-2 个，用于分类、点缀
- **背景色**：1 个，全篇统一
- **文字色**：1-2 个（深色+浅色，用于不同背景）

### 4.2 颜色应用
- **同类文案**：颜色一致
- **同层级标题**：颜色一致
- **强调色**：只在重点处使用，不超过 10% 面积

### 4.3 对比度
- **文字/背景**：对比度 ≥ 4.5:1
- **层级区分**：高对比度用于重要内容
- **避免纯黑**：正文用深灰 (#333) 替代纯黑 (#000)

---

## 5. 图片规范 (Images)

### 5.1 尺寸统一
- **同类图片**：宽度或高度统一
- **圆角**：统一圆角半径（如 12px 或 24px）
- **边框**：如有边框，全篇统一粗细和颜色

### 5.2 质量要求
- **分辨率**：≥ 150 DPI（投影）
- **比例**：不拉伸变形，保持原始比例
- **清晰度**：无模糊、无锯齿

### 5.3 位置统一
- **图片位置**：同类页面图片在相同位置
- **图文关系**：图片与文字的间距统一

## 7. 常见错误

| 错误 | 正确做法 |
|-----|---------|
| 同一页标题字号不一 | 同层级完全统一 |
| 左右留白不等 | 对称或成比例 |
| 图片大小不一 | 统一宽度/高度 |
| 颜色随意使用 | 限定 3-4 种主色 |
| 文字贴边 | 留出安全边距 |
| 行距忽大忽小 | 统一 1.3-1.5 倍 |

## 8. 左右分栏垂直对齐技巧 (实战经验)

### 8.1 常见对齐需求

| 对齐方式 | 适用场景 | 实现难度 |
|---------|---------|---------|
| **顶部对齐** | 左右顶部内容起点一致 | 简单 |
| **水平中心对齐** | 左侧图片 vs 右侧文案，中心点对齐 | 中等 |
| **底部对齐** | 左右底部内容终点一致 | 简单 |
| **垂直居中** | 右侧内容在左栏整个高度中居中 | 简单 |

### 8.2 水平中心对齐实现方案

**场景**：左侧有标题+副标题+图片框，右侧只有文案框，要求右侧文案中心 = 左侧图片框中心。

**解决方案**：

```css
/* 左侧结构 */
.left {
  display: flex;
  flex-direction: column;
}
.title-chip { margin-top: 7mm; }  /* 主标题 */
.en-title { margin-top: 12px; }   /* 副标题 */
.hero-box { 
  margin-top: 8mm; 
  flex: 1;  /* 图片框占据剩余空间 */
}

/* 右侧对齐实现 */
.right {
  display: flex;
  flex-direction: column;
}
.right-spacer {
  /* 关键：高度 = 左侧标题区域高度 */
  height: calc(7mm + [title-height] + 12px + [subtitle-height] + 8mm);
  flex-shrink: 0;
}
.right-content {
  flex: 1;
  display: flex;
  flex-direction: column;
  justify-content: center;  /* 文案在此区域垂直居中 */
}
.text-card {
  /* 文案框在 right-content 中居中 */
}
```

**HTML 结构**：
```html
<div class="right">
  <div class="right-spacer"></div>  <!-- 占位，模拟左侧标题区域 -->
  <div class="right-content">
    <div class="text-card">
      <!-- 文案内容 -->
    </div>
  </div>
</div>
```

### 8.3 经验总结

**常见误区**：
- ❌ `justify-content: center` 直接用在 `.right` → 文案在整个左栏高度中居中，不对齐图片
- ❌ `padding-top` 粗略估算 → 对齐不精确
- ❌ 理解偏差：用户说的"中心对齐" vs "顶部对齐"

**正确做法**：
- ✅ **先明确对齐基准点**：问清楚是"顶部对齐"、"中心对齐"还是"底部对齐"
- ✅ **计算精确高度**：标题 + 间距 + 图片框起点 = spacer 高度
- ✅ **分区域处理**：spacer 区 + content 区，content 区内再居中
- ✅ **用截图验证**：不要假设，让用户截图确认

**沟通模板**：
```
请确认对齐方式：
A. 右侧文案顶部 ↔ 左侧图片顶部对齐
B. 右侧文案中心 ↔ 左侧图片中心对齐  
C. 右侧文案底部 ↔ 左侧图片底部对齐
D. 其他：_____
```

### 8.4 快速计算公式

```
左侧结构高度分解：
- 主标题：margin-top + 实际高度
- 副标题：margin-top + 实际高度
- 图片框起点：margin-top

spacer 高度 = 主标题 margin-top + 主标题高度 + 副标题 margin-top + 副标题高度 + 图片框 margin-top
```

**估算参考**（基于字号）：
- 30px 标题高度 ≈ 42px
- 26px 副标题高度 ≈ 36px
- 12px margin ≈ 17px (以 96dpi 计算)
- 7mm ≈ 26px
- 8mm ≈ 30px

## 9. 排版黄金法则

1. **统一优先**：先统一，再变化
2. **对齐即美**：对齐是最简单的美化
3. **留白呼吸**：不要把页面填满
4. **重复节奏**：重复创造专业感
5. **对比突出**：用对比引导视线
